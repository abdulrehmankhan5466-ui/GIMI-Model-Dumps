# Neverness to Everness (NTE) — Custom Blender Dumps

Place each NTE dump inside its own subfolder:

```text
NTE/
└── <Character_Vehicle_or_Asset_Name>/
    ├── hash.json
    ├── *.txt / *.vb / *.ib / *.buf
    └── *.dds / *.png
```

### Supported Blender Import Formats
- **3DMigoto / XXMI Frame Analysis & Buffer Dumps**: `.txt` topology dumps or `.vb` / `.ib` / `.buf` buffers with `hash.json` and `.dds` textures.
