# Wuthering Waves — Custom WWMI / Blender Dumps

Place each Wuthering Waves dump inside its own subfolder:

```text
Wuwa/
└── <Resonator_Weapon_or_Echo_Name>/
    ├── hash.json
    ├── *.txt / *.vb / *.ib / *.buf
    └── *.dds / *.png
```

### Supported Blender Import Formats
- **WWMI / 3DMigoto Frame Analysis Dumps**: `.txt` topology dumps or extracted `.buf` / `.vb` / `.ib` buffers with `hash.json` and `.dds` textures.
